# אותיות ומספרים

אפליקציית ווב (PWA) ללימוד אותיות ומספרים בגיל הרך, לאייפד ולאייפון. אין צורך ב-App Store או בחשבון מפתח.

**מה יש בה:**
- **כרטיסיות:** אות גדולה עם תמונה ומילה, שמושמעות בקול. במספרים מקישים על החפצים וסופרים בקול.
- **איפה?:** האפליקציה שואלת "איפה האות בית?" ומציגה 2 אפשרויות לבחירה. אחרי כמה הצלחות זה עולה ל-3. אין "טעות": אפשרות שגויה רק נעלמת.
- **מציירים:** כדור ⭐ נע בתוך צורת האות ולא יכול לצאת ממנה. מספיק להזיז את האצבע בכיוון הכללי, ולפי הסדר והכיוון של כל קו.

## לנסות על האייפד מהמחשב (באותה רשת Wi‑Fi)

```sh
cd learn_letters
python3 -m http.server 8000
```

באייפד פותחים ב-Safari את `http://<כתובת-ה-IP-של-המק>:8000`. את הכתובת אפשר למצוא בהגדרות המערכת ← Wi‑Fi ← פרטים.
בכתובת `http` רגילה הכול עובד חוץ מעבודה בלי אינטרנט. בשביל זה צריך HTTPS, ראו למטה.

## פרסום בחינם (GitHub Pages)

1. יוצרים מאגר ב-GitHub ומעלים אליו את התיקייה.
2. נכנסים ל-Settings ← Pages ← Deploy from a branch ← `main` / root.
3. אחרי דקה האתר זמין בכתובת `https://<user>.github.io/<repo>/`.

Netlify או Cloudflare Pages עובדים באותה צורה: גוררים את התיקייה וזהו.

## התקנה על האייפד / אייפון

1. פותחים את הכתובת ב-Safari ← כפתור שיתוף ← **הוסף למסך הבית**.
2. האפליקציה נפתחת במסך מלא ועובדת גם בלי אינטרנט.
3. **גישה מודרכת**, כדי שהילדה לא תצא מהאפליקציה: הגדרות ← נגישות ← גישה מודרכת ← להפעיל. בתוך האפליקציה לוחצים 3 פעמים על הכפתור הצדדי/העליון כדי לנעול, ושוב 3 פעמים כדי לשחרר.

עדכונים: האתר מתעדכן לבד 1–2 דקות אחרי כל העלאה. האפליקציה המותקנת מורידה את העדכון ברקע, והוא מופיע בפתיחה הבאה. כדי לפתוח מחדש, סוגרים את האפליקציה לגמרי מתוך מחליף האפליקציות. **בכל עדכון מעלים את `VERSION` ב-`sw.js`** (למשל `v3` ל-`v4`).

## קולות

כברירת מחדל המכשיר מקריא את הטקסטים בקול העברי המובנה שלו. כדי לשמוע קול טבעי יותר יש שתי אפשרויות:

**קול נוירוני (מומלץ להתחלה):** מריצים מהטרמינל הרגיל:

```sh
pip3 install edge-tts
node tools/make-voices.mjs                 # קול נשי (Hila)
node tools/make-voices.mjs --voice he-IL-AvriNeural --force   # קול גברי (Avri)
```

הסקריפט יוצר קובץ MP3 לכל משפט בתיקייה `audio/` ומעדכן את `audio/manifest.json`.

### מצב הקלטת הורים

כדי שהאפליקציה תדבר בקול שלכם:

1. במסך הבית **לוחצים ומחזיקים את גלגל השיניים** הקטן בפינה, בערך שנייה וחצי. לחיצה קצרה לא פותחת אותו, כך שהילדה לא תיכנס בטעות.
2. נפתחת רשימה של כל 95 ההקלטות: כללי, עידודים, ולכל אות שם, מילה ושאלה, וגם המספרים. ליד כל אחת מסומן אם כבר הוקלטה.
3. לוחצים על **להתחיל להקליט**. מקריאים את הטקסט שעל המסך, לוחצים על הכפתור האדום כדי להתחיל ושוב כדי לסיים. ההקלטה מושמעת מיד, ואז עוברים ל**הבא**. מה שלא מוקלט נשאר בקול המובנה.

השקט בהתחלה ובסוף נחתך אוטומטית, ועוצמת הקול מאוזנת כך שכל ההקלטות יישמעו דומה.

חשוב לדעת:
- **מיקרופון עובד רק בכתובת `https`**, כלומר אחרי פרסום. בכתובת `http://...:8000` המקומית הדפדפן חוסם אותו.
- כדאי להקליט **מתוך האפליקציה שבמסך הבית**. ב-iOS ל-Safari ולאפליקציה שבמסך הבית יש אחסון נפרד.
- ההקלטות נשמרות **רק במכשיר**. הכפתור **גיבוי / העברה** יוצר קובץ zip שאפשר לשלוח ב-AirDrop או לשמור בקבצים. **שחזור מגיבוי** טוען אותו באייפון או אחרי התקנה מחדש.
- אפשר גם לפתוח את ה-zip לתוך התיקייה `audio/` ולפרסם מחדש (ולהעלות את `VERSION` ב-`sw.js`). אז ההקלטות הופכות לחלק מהאפליקציה בכל המכשירים. שימו לב שאם המאגר ציבורי, גם ההקלטות יהיו ציבוריות.

## שינויים בתוכן

- **מילים, תמונות (אימוג'י) ומספרים:** `js/data.js`
- **צורת האותיות לציור** (הקווים, הסדר והכיוון): `js/strokes.js`. אפשר לבדוק אותן בעמוד `tools/strokes-preview.html`, שמציג את הקווים מעל הגופן.
- **רגישות הציור:** הקבועים בראש `js/tracer.js`, כמו כמה רחוק מהקו מותר להיות וכמה קרוב לכדור צריך להתחיל.

## כלי פיתוח (`tools/`)

אלה כלים לפיתוח בלבד, והאפליקציה לא משתמשת בהם.

- `webshot.swift`: צילום מסך ב-WebKit, אותו מנוע של Safari, בלי שרת:
  `swiftc -O tools/webshot.swift -o tools/.build/webshot`
- `shots.sh`: צילום של כל המסכים בגדלים של אייפד ואייפון.
- `trace-test.html`: מדמה אצבע "לא מדויקת" על כל 22 האותיות והמספרים, ובודק שהציור מצליח ושאי אפשר לדלג.
- `audio-test.html`: בודק שהקראות לא נערמות זו על זו כשמקישים מהר.
- `recording-test.html`: בודק את מצב ההקלטה עם מיקרופון מדומה: חיתוך שקט, איזון עוצמה, שמירה, גיבוי ושחזור, וכל הזרימה במסך.
